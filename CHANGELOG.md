## [0.1.0] - 2026-10-28

### Added

- Folder-as-database listing of HTML files and claude.ai Artifact `.url` bookmarks under `~/artifacts`
- Tags, with one-click filtering from the sidebar or any list row
- Full-text search
- Split preview with up to 4 panes and per-pane zoom
- Zen mode
- Focus mode: an always-on-top floating mini window with a global shortcut
- Recent items
- Auto-refresh for linked Artifacts
- Chrome cookie import for claude.ai
- Menu bar residency
- Quick-open palette (⌘K)
- Version history with restore
- Claude Code plugin: skills and an Artifact publish hook
